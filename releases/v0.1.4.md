## [v0.1.4] - 2026-06-01
Primeira release oficial do **Settupper**, um gerenciador de pacotes declarativo com interface de terminal (TUI) interativa projetado para facilitar a padronização e automação de ambientes no Fedora, Ubuntu, macOS e Windows.
### 🚀 Funcionalidades
- **Interface de Terminal Interativa (TUI)**: Painel completo construído com o framework Ratatui, que inclui lista de pacotes, descrição em detalhes e logs de execução em tempo real.
- **Suporte Multi-plataforma**: Execução nativa e comandos pré-configurados para **Ubuntu**, **Fedora**, **macOS** e **Windows**.
- **Resolução de Dependências**: Ordenação topológica que assegura que as dependências declaradas de um aplicativo sejam instaladas antes dele (por exemplo, instalar o `git` antes do `nvm`).
- **Comportamento Inteligente ("Smart Action")**:
  - **Smart Individual**: Verifica se o aplicativo já está presente e instala ou atualiza de acordo com o estado detectado.
  - **Smart All (`Shift+A`)**: Roda a fila completa de instalação e atualização para todos os aplicativos visíveis de uma vez, respeitando a ordem de dependência.
- **Modo de Visualização Sem Executar (`--dry-run`)**: Permite simular a instalação ou atualização, exibindo no log exatamente quais comandos seriam rodados.
- **Suporte a Reboot pós-instalação**: Possibilidade de indicar se um pacote precisa de reinicialização para pausar temporariamente a execução da TUI e notificar o usuário.
- **Agrupamento**: Permite organizar e filtrar pacotes na interface através de grupos definidos na configuração.
- **Integração com XDG**: Carregamento automático de configurações a partir de caminhos padrão como `~/.config/settupper/packages.yaml`.
### 🛠️ Modificações Recentes
- **Makefile Aprimorado**: O Makefile agora verifica automaticamente o sistema operacional e a presença de gerenciadores de pacotes suportados (`dnf`, `apt-get`, `pacman`, `zypper`, `brew`) para instalar o `patchelf` (essencial para compilação no Linux com Nuitka) se ele não estiver instalado.
