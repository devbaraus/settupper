## [v0.1.6] - 2026-06-11

Settupper v0.1.6 adds configuration schema support and allows package
configurations to be loaded directly from remote URLs.

### Added

- Added a JSON Schema for Settupper YAML and JSON package configuration files.
- Added a `$schema` reference to the example `packages.yaml` for editor
  validation and autocompletion.
- Added support for passing an HTTP or HTTPS configuration URL to the CLI.
- Added automatic JSON/YAML format detection for remote URLs, including URLs
  with query strings or fragments.
- Added tests for loading remote YAML configurations and detecting JSON files
  from URL paths.

### Changed

- Updated the CLI configuration argument and help text to accept either a local
  path or a URL.
- Added `ureq` for synchronous HTTP configuration downloads.
- Bumped the crate version from `0.1.5` to `0.1.6`.
