## [v0.1.5] - 2026-06-01

Settupper v0.1.5 is a maintenance release focused on English-language polish, release metadata, and a clearer terminal UI.

### Changed

- Bumped the crate version from `0.1.4` to `0.1.5`.
- Updated README installation examples to reference `v0.1.5`.
- Translated README content, sample package metadata, and installer output from Portuguese to English.
- Translated CLI help, TUI labels, status logs, and external-terminal messages to English.
- Refined the TUI footer and details panel labels for clearer keyboard guidance and package status details.

### Fixed

- Updated tests that assert user-facing English status messages.
- Refreshed `Cargo.lock` for the `0.1.5` package version and dependency resolution.
